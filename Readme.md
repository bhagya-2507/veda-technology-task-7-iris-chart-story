# Iris Flower Data Visualization & Chart Story

## VEDA Technology Data Analytics Internship – Level 1 Day 7

### Task: First Chart Story – Turning Numbers into a Narrative

## 📌 Project Overview

This project was completed as part of the VEDA Technology Data Analytics Internship.

The objective of this task was to transform numerical data into a clear and meaningful visual story using simple charts.

## 📊 Dataset

The project uses the Iris dataset, which contains 150 observations of three Iris flower species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The dataset includes:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## 🛠️ Tool Used

- Microsoft Excel

## 📈 Charts Created

### 1. Average Petal Length by Iris Species
A bar chart was used to compare the average petal length of the three Iris species.

**Key Takeaway:** Iris Virginica has the longest average petal length, while Iris Setosa has the shortest.

### 2. Average Sepal Length by Iris Species
A column chart was used to compare average sepal length.

**Key Takeaway:** Iris Virginica has the highest average sepal length among the three species.

### 3. Distribution of Iris Species
A pie chart was used to show the distribution of observations across the species.

**Key Takeaway:** Each Iris species represents approximately 33.3% of the dataset.

### 4. Average Petal Width Across Iris Species
A line chart was used to compare changes in average petal width across the species.

**Key Takeaway:** Average petal width increases substantially from Setosa to Virginica.

## 📖 Overall Data Story

The analysis shows clear differences between the three Iris flower species. Iris Virginica generally has the largest measurements, while Iris Setosa has the smallest petal measurements. Since each species contains an equal number of observations, the comparison is balanced. Overall, petal length and petal width provide strong visual differences between the species.
